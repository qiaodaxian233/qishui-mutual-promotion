# 汽水音乐独立音乐人互推平台

> 一个让独立音乐人互相听见的地方,不是刷量工具。

## 项目定位

- **服务对象**:独立音乐人 + 小众音乐爱好者
- **核心机制**:基于积分的互推任务(点赞、评论、播放)
- **价值观**:真实互动,凭良心

## 核心规则

- 新用户初始 100 积分
- 积分可买置顶位(加粗 + 🔥 标签)
- 不能赚自己发布任务的积分
- 注册必须邮箱认证(屏蔽临时邮箱)
- 同 IP + 设备指纹双因子去重
- 自动验证:点赞 + 播放到指定秒数

## 技术栈(待定)

- 后端:Node.js / Go
- 数据库:MySQL + Redis
- OCR:百度云 / 阿里云
- 存储:本地 40G + 对象存储(七牛云 / 阿里云 OSS)
